# Git Práctica Trabajo

Este repositorio es un proyecto de práctica para aprender y aplicar el uso de **Git y GitHub**.

## 🎯 Objetivo
- Crear y manejar ramas (`feat/`, `fix/`, `docs/`).
- Realizar commits con buenas prácticas.
- Hacer merges hacia la rama principal.
- Simular un flujo de trabajo colaborativo.

## 📂 Archivos iniciales
- `index.html` → Página principal del proyecto.
- `README.md` → Documentación del repositorio.

## 🚀 Flujo de trabajo
1. Crear una nueva rama para cada cambio.
2. Hacer commits con mensajes descriptivos.
3. Realizar un merge a `main`.
4. Eliminar ramas ya integradas.

---

💡 Este repositorio servirá como material de aprendizaje para comprender el flujo básico de trabajo con Git.
